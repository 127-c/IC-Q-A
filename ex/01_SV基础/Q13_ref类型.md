## 🎯 题目


**题目**: 说一下ref类型，你用到过吗？

**核心要点**:
- `ref` 是引用传递，不是值传递
- 向子程序传递数组时应尽量使用 `ref` 以获得最佳性能（避免拷贝大数组）
- 如果不希望子程序修改数组值，使用 `const ref`
- 在task中通过ref修改的变量，对调用者立即可见
- `ref` 参数不允许使用 `#` 延迟（因为它是引用，需要立即反映变化）

**代码示例**:
```systemverilog
task modify(ref int arr[]);
  arr[0] = 999;  // 直接修改调用者的数组
endtask
```
