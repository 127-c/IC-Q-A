# Q29. 事件的触发

> 🏷️ SystemVerilog 基础 | 📝 练习

---

## 🎯 题目


**题目**: 事件的触发怎么实现？

**核心要点**:
- 触发事件使用 `->` 操作符
- 等待事件使用 `@(event)` 或 `wait(event.triggered)`
- `@` 是边沿敏感（需要先等待再触发）
- `wait(event.triggered)` 是电平敏感（触发后一直为真，在当前时间步内有效）

**代码示例**:
```systemverilog
event e;
// 线程1: 触发
-> e;

// 线程2: 等待
@(e);                    // 边沿触发等待
wait(e.triggered);       // 电平触发等待

// @ vs wait的区别:
// @(e): 如果e已经触发过了，@(e)会永久阻塞！
// wait(e.triggered): e触发后在整个time slot内为真，不会错过
```


Q29. 事件的触发 

- 用来触发事件时，使用->；
- 用来等待事件使用@或者wait。
