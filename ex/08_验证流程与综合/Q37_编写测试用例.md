## 🎯 题目


**题目**: 怎么编写测试用例？

**核心要点**:
测试用例主要是编写sequence，在body()中根据测试功能要求写相应的激励。

**步骤**:
1. 继承 `uvm_sequence` 创建自己的sequence类
2. 在 `body()` task中编写激励逻辑
3. 通过 `start_item()` → `randomize()` → `finish_item()` 发送transaction
4. 通过 `raise_objection` / `drop_objection` 控制仿真时长
5. 在test的 `run_phase` 中启动sequence

**代码示例**:
```systemverilog
class my_test_sequence extends uvm_sequence #(my_item);
  `uvm_object_utils(my_test_sequence)

  task body();
    my_item item;
    repeat(100) begin
      item = my_item::type_id::create("item");
      start_item(item);
      item.randomize() with { addr inside {[0:255]}; };
      finish_item(item);
    end
  endtask
endclass
```
