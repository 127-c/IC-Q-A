## 🎯 题目

你的验证环境是什么？目录结构是什么样的？（面试高频题）

---

**回答要点**:

使用UVM验证方法学搭建TB，通常在VCS/Questa/XCelium平台仿真。

**典型目录结构**:
```
project/
├── rtl/                  # DUT RTL源代码
│   ├── module_a.v
│   └── module_b.v
├── tb/                   # 验证环境
│   ├── top.sv            # 顶层(top + interface例化 + run_test)
│   ├── interface.sv      # 接口定义(含clocking block)
│   ├── my_pkg.sv         # package(import uvm_pkg + include所有文件)
│   ├── item.sv           # transaction/sequence_item
│   ├── sequence_lib.sv   # sequence库
│   ├── sequencer.sv
│   ├── driver.sv
│   ├── monitor.sv
│   ├── agent.sv
│   ├── model.sv          # reference model
│   ├── scoreboard.sv
│   ├── coverage.sv       # 功能覆盖率collector
│   ├── env.sv
│   └── test_base.sv      # test基类
├── tests/                # 具体测试用例
│   ├── test_smoke.sv
│   ├── test_random.sv
│   └── test_corner.sv
├── sim/                  # 仿真运行目录
│   ├── Makefile          # 编译+运行+覆盖率收集
│   └── run.sh
├── scripts/              # 脚本
│   └── regress.py        # 回归测试脚本
└── doc/                  # 文档
    └── verification_plan.xlsx
```

## ✅ 参考答案

<details>
<summary>点击展开完整答案</summary>

使用UVM验证方法学搭建的TB，在VCS平台进行仿真。目录结构主要由以下几部分构成:

| 目录 | 用途 |
|------|------|
| rtl/ | DUT RTL设计代码 |
| tb/ | 验证环境所有组件 |
| tests/ | 测试用例(继承自test_base) |
| sim/ | 仿真工作目录(Makefile + 波形) |
| scripts/ | 回归脚本、结果分析脚本 |
| doc/ | 验证计划、覆盖率报告 |

</details>
