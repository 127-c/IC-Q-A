## 🎯 题目


**题目**: 请画出一个简单的UVM验证平台框图。

**UVM验证平台结构**:

```
┌─────────────────────────────────────────────────┐
│                   uvm_test                       │
│  ┌─────────────────────────────────────────────┐│
│  │                  env                         ││
│  │  ┌──────────────────┐  ┌──────────────────┐ ││
│  │  │  agent (active)   │  │  agent (passive) │ ││
│  │  │  ┌────────────┐   │  │  ┌────────────┐  │ ││
│  │  │  │ sequencer  │   │  │  │  monitor   │  │ ││
│  │  │  │    ↕       │   │  │  └─────┬──────┘  │ ││
│  │  │  │  driver    │   │  │        │         │ ││
│  │  │  └─────┬──────┘   │  │        │         │ ││
│  │  │  ┌─────┴──────┐   │  │        │         │ ││
│  │  │  │  monitor   │   │  │        │         │ ││
│  │  │  └─────┬──────┘   │  │        │         │ ││
│  │  └────────┼──────────┘  └────────┼─────────┘ ││
│  │           │analysis_port         │            ││
│  │  ┌────────┴──────────────────────┴──────────┐ ││
│  │  │           scoreboard + coverage          │ ││
│  │  └──────────────────────────────────────────┘ ││
│  └──────────────────────┬───────────────────────┘│
└─────────────────────────┼────────────────────────┘
                          │ Interface
                   ┌──────┴──────┐
                   │     DUT     │
                   └─────────────┘
```

**各组件职责**:
- **sequence**: 产生激励数据（transaction）
- **sequencer**: 仲裁和管理sequence发送的item
- **driver**: 从sequencer获取item，按接口时序驱动到DUT
- **monitor**: 监测DUT接口信号，打包成item发送出去
- **agent**: 封装driver、monitor、sequencer
- **reference model**: 实现与DUT相同的功能（高层模型）
- **scoreboard**: 比对各路数据，判断PASS/FAIL
